Miniatures

Test Mechanics for The Model Nation

Simulates how symbolic, political, cultural, and social forces interact across a grid-based landscape. When placing miniatures on the map, you can observe how values spread, how different forces collide or reinforce one another, how decay emerges, and how ruins leave behind a residual presence.

Miniatures

Miniatures act as agents within the system. Each one has:

  • A position on the grid
  • Nine sociopolitical attributes, each ranging from −1 to +1
  • A radius per attribute, determining how far its influence spreads
  • A decay index from 0 (new) to 1 (ruin)
  • A “state” determined by decay: Prototype, Transparent, Model, or Ruin
These agents influence the world around them, and the world responds through time-dependent changes.

Heatmaps

The system generates several heatmap layers:

  • Attribute heatmaps showing the spatial intensity of each attribute.
  • Value Index (VI), a composite score combining all attributes through weighted contributions, synergies, penalties, and stability terms.
  • Non-Human Index (NHI), created by miniatures that have reached a ruined state, representing post-human or abandoned zones.

All heatmaps update in real time as the miniature configuration changes.

Value Index (VI)

The Value Index compresses the nine attributes into a single interpretable value. It uses:

  • Linear weights for each attribute
  • Synergy terms between specific attribute pairs
  • Penalties for extreme or off-target values
  • A stability bonus based on certain combinations
  • A nonlinear squashing step to keep results within −1 to +1

The VI is configurable through sliders, allowing exploration of different “world logics.”

Time and Decay

A tick-based simulation drives the temporal behavior. Each miniature periodically samples the Value Index beneath it:

  • Negative VI causes decay to increase.
  • Positive VI allows partial recovery.

As decay grows, the miniature’s attributes weaken and its radii contract. Eventually, it transitions into a ruined state, which then contributes to the Non-Human Index. This creates a closed feedback loop between attributes, the environment, and time.

Non-Human Index (NHI)

When miniatures become ruined, they begin generating a separate diffusion field. This produces the Non-Human Index, representing residual presence, abandonment, or post-human influence. It acts as an additional layer of spatial memory.

Interaction

You can:

  • Place miniatures manually or at random positions
  • Randomize attributes and radii
  • Click-to-place directly on the heatmap
  • Hover to inspect miniature data or local values on the heatmap
  • Run, pause, and reset the tick-based simulation
  • Adjust all parameters of the Value Index and decay behaviour live
